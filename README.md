# SEATO — פרויקט הזמנת שולחנות עם JavaScript ו-SQLite

אין צורך ב-Python. ממשק המשתמש כתוב ב-HTML/CSS/JavaScript והשרת ב-**Node.js (JavaScript)**. בסיס הנתונים הוא SQLite.

## הפעלה

1. התקינו **Node.js 22.13 ומעלה** (מומלץ 24 LTS).
2. פתחו Terminal בתיקיית הפרויקט והקלידו `node server.js`.
3. היכנסו ל-`http://localhost:8000`.
4. בהרצה הראשונה נוצר אוטומטית `seato.db` — מסד הנתונים האמיתי.

אין צורך להתקין חבילות npm; הפרויקט משתמש במודול `node:sqlite` המובנה בגרסאות Node החדשות.

## ERD — ארבע ישויות

- `customers`: מפתח ראשי `customer_id`; שם וטלפון.
- `restaurants`: מפתח ראשי `restaurant_id`; שם, עיר, מטבח.
- `restaurant_tables`: מפתח ראשי `table_id`; מפתח זר `restaurant_id`.
- `reservations`: מפתח ראשי `reservation_id`; מפתחות זרים `customer_id` ו-`table_id`; תאריך ושעת התחלה וסיום, מספר סועדים, סטטוס.

קשרים: לקוח 1:N הזמנות; מסעדה 1:N שולחנות; שולחן 1:N הזמנות לאורך זמן.

## התנהגות

- 35 מסעדות הדגמה עם שולחנות לדוגמה.
- הלקוח בוחר מסעדה, תאריך, שעה, כמות סועדים ושולחן פנוי.
- הזמנה חדשה נכתבת למסד הנתונים ומקבלת מספר אישור כגון `ST-000001`.
- מניעת הזמנות חופפות לאותו שולחן (משך הזמנה: שעתיים).
- צפייה בהזמנות וביטולן לפי מספר טלפון; הפקת אישור ותזכורת ליומן.

## חשוב

זו מערכת לימודית מקומית, ללא התחברות והרשאות משתמשים. אין להזין פרטים אישיים אמיתיים או לפרסם את השרת באינטרנט. שמות המסעדות הם דוגמאות. הזמינות אינה מחוברת למסעדות אמיתיות.

## התקנה בטלפון (PWA)

האפליקציה כוללת manifest, אייקונים ו-service worker. כדי להתקין באייפון יש לפרוס את השרת בכתובת HTTPS ציבורית, לפתוח ב-Safari, לבחור שיתוף > הוסף למסך הבית. ממשק בסיסי עשוי להיטען ללא רשת לאחר ביקור קודם, אך הזמנות דורשות חיבור לשרת ולמסד הנתונים.

אפשר לבדוק בטלפון באותה רשת Wi-Fi על ידי פתיחת `http://IP-של-המחשב:8000` כאשר השרת פועל, אך התקנת PWA מלאה דורשת HTTPS.

השרת תומך במשתנה סביבה `PORT` לשירותי ענן וב-`HOST` (ברירת מחדל 0.0.0.0). לפריסה בענן יש להגדיר אחסון קבוע לקובץ SQLite; בלעדיו הזמנות עלולות להימחק בפריסה מחדש. לפני חשיפה ציבורית יש להוסיף אימות והרשאות כדי לא לחשוף פרטי לקוחות והזמנות.
